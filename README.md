## Task Control

Task Control is a project management application designed to help users organize and track their tasks efficiently. Unlike a simple to-do list, Task Control visualizes tasks in a Kanban board , allowing users to easily move tasks between different stages (e.g., To Do, In Progress, Done).

### Key Features

- Create, update, and delete tasks
- Organize tasks into customizable columns (Kanban style)
- Drag-and-drop interface for task management
- Real-time updates and synchronization
